This app uses a free Google Apps Script as its backend — no cost, no third-party services, fully under your Google account. It stores all song data in a JSON file on your Drive and also writes the Excel export there.

Open script.google.com, create a new project, paste the script below, click Deploy → New deployment → Web app, set Execute as: Me and Who has access: Anyone, then copy the Web App URL.
